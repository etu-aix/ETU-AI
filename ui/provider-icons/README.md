# Provider icons

These SVG marks are stored locally so the interface does not depend on a remote icon CDN.

- `anthropic.svg`, `deepseek.svg`, `gemini.svg`, `mistral.svg`, `nvidia.svg`, `openrouter.svg`, `perplexity.svg`, and `github-models.svg` are from [Simple Icons](https://github.com/simple-icons/simple-icons), version 16.33.0, under CC0 1.0.
- The remaining marks are from [Lobe Icons](https://github.com/lobehub/lobe-icons), package `@lobehub/icons-static-svg` version 1.95.1, under MIT.
- `xai.svg` is the Grok SVG supplied by the user.

Provider names, marks, and trademarks remain the property of their respective owners. Generic compatible endpoints retain a text mark because they have no single provider brand.
