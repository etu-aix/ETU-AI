# Platform and backend marks

The interface calls these SVG files through `ui/svg-manager.js`.

- `macos.svg` (Apple), `vulkan.svg`, and `nvidia.svg` are from [Simple Icons](https://github.com/simple-icons/simple-icons), under CC0 1.0. The NVIDIA mark is also used in `ui/provider-icons/`.
- `windows.svg` and `linux.svg` are project drawings.
